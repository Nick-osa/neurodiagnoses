# PPMI Project

This folder contains data, notebooks, and experiments related to the Parkinson's Progression Markers Initiative (PPMI) dataset.

## Structure

- `data/` — Raw and processed PPMI data files  
- `notebooks/` — Exploratory data analysis and modeling notebooks  
- `experiments/` — Scripts and notebooks for PPMI-specific machine learning experiments  

## Objective

Apply machine learning methods to PPMI data to identify biomarkers and develop predictive models for Parkinson’s disease progression, similar to approaches used in the ADNI neurodiagnosis project.
