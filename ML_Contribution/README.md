# ML Project: Neurodiagnoses Contribution

This folder contains the work developed as contribution to the project and also as part of my master's thesis in *Health Engineering and AI for One Health*. The goal is to explore and improve machine learning methods for neurodiagnostic applications using multimodal data.

## Objectives

- Implement alternative models to the baseline RandomForestClassifier.
- Compare and validate models using open datasets (e.g., ADNI, UK Biobank).
- Contribute to model interpretability and visualization.
- Integrate clinical and imaging biomarkers.
- Attempt to integrate omics data into a ML mode/pipeline
- Document all experiments and findings.


## Notes

- Work is based on the [Neurodiagnoses](https://github.com/Fundacion-de-Neurociencias/neurodiagnoses) project.
- My fork of the project: [github.com/Nick-osa/neurodiagnoses](https://github.com/Nick-osa/neurodiagnoses)


## Folder Structure

- `documents/` – Notes, logs, progress updates.
- `data/` – Training, testing datasets.
- `models/` – Trained ML models and configs.
- `results/` – Model metrics, evaluation reports.
- `workflows scripts/` – Flow diagrams, design drafts.
- `references/` – Papers, PDFs, background material.
- `pdfs/` – saved pdf and Biomarkers.
- `reports/` – Thesis drafts and feedback.
- `visualizations/` – Plots, attention maps, figures.
